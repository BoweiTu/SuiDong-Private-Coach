## 项目简介

**随动私教**是一款面向健身人群的对话式 AI 智能体，定位为**平价 AI 私教 + 营养师**。它根据用户当日的身体疲劳状态、可用时长、训练目标和场地，自动生成个性化训练方案；同时支持输入餐食内容进行营养精准测算，帮助用户科学管理训练与饮食。

> 本项目为 **TRAE AI 创造力大赛 · 生活娱乐赛道** 参赛作品，由非计算机专业学生借助 TRAE（AI 编程工具）从零完成开发。

## 项目背景

### 痛点洞察

作为一名健身爱好者，我在训练过程中深刻感受到市面健身产品的两大断层：

| 方案 | 优势 | 劣势 |
|------|------|------|
| 线下私教 | 专业、个性化 | 300-500 元/小时，长期难以承受 |
| 健身 APP | 便宜、便捷 | 计划固定僵化，不根据当日状态调整 |

此外，**营养摄入无法量化**也是普遍问题——用户不知道自己吃的东西含多少蛋白质、碳水、脂肪，训练和饮食无法精准匹配目标。

### 产品定位

用 AI 的能力提供**接近私教的个性化服务**，但价格只有私教的几十分之一——"一杯咖啡的价格，享受专业级服务"。

### 目标用户

- **健身初学者**：零基础，渴望入门但缺乏指导，面临训练知识空白、动作姿势错误、营养概念模糊等问题
- **有一定基础者**：已有训练经验，追求更高效率，面临计划僵化、缺乏个性化、营养难以量化等问题

## 核心功能

### 一、多维度实时自适应训练计划调整

根据用户输入的 6 个身体区域疲劳度打分（1-5 分）、可用时长、训练目标、训练强度、训练场地，自动生成个性化训练方案：

- **疲劳度感知**：6 区域滑块打分（胸/肩/背/腿/肱二头肌/肱三头肌），高疲劳区域自动降低训练量
- **智能动作编排**：从健身房 / 居家两套动作库中随机组合，避免计划僵化
- **自适应参数**：根据疲劳度、强度、目标动态计算组数、次数、建议重量、组间休息
- **训练指导**：附训练注意事项提示 + 针对训练肌群的拉伸要点

### 二、三餐营养量化与剩余营养素测算

- **食物识别**：输入餐食描述（如"一碗米饭+鸡胸肉+青菜"），自动匹配食物数据库
- **营养计算**：实时计算热量、蛋白质、碳水、脂肪摄入量
- **目标跟踪**：结合健身目标计算今日剩余需补充的蛋白/碳水/脂肪克数
- **饮食建议**：根据目标给出下一餐搭配方向

### 三、AI 问答助手

内置两个基于关键词匹配的知识库问答区：

- **AI 私教问答**：解答动作细节、训练技巧（卧推姿势、深蹲注意事项等）
- **AI 营养师问答**：解答饮食搭配、营养摄入（增肌期早餐、减脂期晚餐等）

## 项目结构

```
SuiDong-Private-Coach/
├── index.html              # 主页面（HTML 结构 + 内联事件绑定）
├── css/
│   └── style.css           # 自定义样式（渐变/毛玻璃/动画）
├── js/
│   ├── data.js             # 数据层：动作库 / 食物营养库 / 问答知识库
│   └── app.js              # 逻辑层：训练生成 / 营养测算 / 问答交互
├── assets/                 # 截图与静态资源（占位）
├── LICENSE                 # MIT 许可证
├── .gitignore
└── README.md               # 项目说明（本文件）
```

### 架构说明

项目采用**数据-逻辑分离**的分层设计：

- **`data.js`（数据层）**：集中管理三类数据——健身房/居家动作库（各 6 肌群）、食物营养数据库（含数百种食物的卡路里及三大营养素）、私教/营养师问答知识库。纯数据声明，无逻辑依赖。
- **`app.js`（逻辑层）**：承载所有交互逻辑，函数均在全局作用域声明，供 HTML 内联 `onclick` 事件调用。通过 DOM 操作动态渲染训练方案与营养结果。
- **`index.html`（视图层）**：纯页面结构与事件绑定，不包含业务逻辑。

这种分层使数据维护与功能迭代互相独立，便于后续扩展。

## 使用说明

### 生成训练计划

1. 在"训练计划"页，拖动 6 个区域疲劳度滑块（1=状态好，5=很疲劳）
2. 设置可用时长、训练目标、强度、场地
3. 点击"生成训练计划"，等待 AI 生成
4. 查看今日方案：动作列表、组数×次数、建议重量、休息时间、拉伸要点

### 营养测算

1. 切换到"营养测算"页
2. 输入餐食描述（如"一碗米饭+鸡胸肉+青菜"）
3. 选择餐型与健身目标
4. 点击"测算营养"，查看本次摄入、今日已摄入、剩余需补充量

### AI 问答

在对应问答区输入问题（如"卧推的正确姿势是什么？"），AI 会从知识库中匹配关键词返回解答。
